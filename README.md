# Kiln

Kiln is a light AI chat for Android phones, including modest devices such as the Infinix Hot 50i.

You bring your own API keys. Kiln does not ship a shared key.

- [Privacy and keys](docs/privacy.md)
- [Text models](docs/models.md)
- [Voice](docs/voice.md)

## Using it

1. Open Settings and paste a key for the provider you want.
2. Open Models and pick one. If a lab renames a model, type the new id in the model sheet. Kiln sends that id as-is.
3. Write in the box, or use the microphone. Enter sends on a keyboard. On a phone, use the send button.
4. The sun and moon button switches between light and dark. Settings also has a system option.

Chats, keys, and the theme are stored in this browser only.
